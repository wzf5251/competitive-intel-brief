# 竞品监测清单（改这个文件就是改监测范围，不必改提示词）

> 首次运行由技能自动生成。直接编辑，下次运行自动生效。
> 竞品行格式：`- 名称 | 企业 | 关系 | 管理属性 | 规格 | 治疗领域/适应症 | tier | 预设`
> `tier` 填 `deep`（深监控，在 36 字段字典内按预设取 20–22 项）或 `shallow`（浅监控，固定 10 字段）；不填默认 `shallow`。深监控竞品在 Excel 台账里整行占一个**专属色**（每家一色：淡蓝/淡紫/淡青/淡粉，按名单顺序分配），浅监控留白——**这是唯一按 tier 影响外观的地方，字段该取多少仍按本节规则**。
> `预设` 填 `price` / `access` / `tender` / `all`，决定深监控填哪些字段；不填则由技能按本期决策问题选，并在矩阵统计行标明。
> 关系填「直接 / 间接 / 潜在」；管理属性填「药品 / 三类器械 / 二类器械 / 化妆品」。
> 缺项按默认走，不报错：缺 `entry_mode` 按 `watch`；缺 `our_price` 时价格对照整列写「未提供」；缺 `file_label` 按 tier 自动生成产品(规格)段。
> 注意：36 项字段定义是固定的，选不选是本期的事，删不删不是——要换关注面，改预设即可。

## 入口模式

```yaml
entry_mode: watch      # watch=我知道盯谁（E1）｜discover=帮我找竞品（E2）｜scan=我怕漏掉新对手（E3）
```

- `watch`：按下面「竞品」段跑矩阵，最常用。
- `discover`：只填「我方产品」段，技能反向发现候选池，**不跑矩阵**；你勾选后把选中的写进「竞品」段并改成 `watch`。
- `scan`：不填竞品，只按「领域扫描规则」每周出事件行，全部进线索区。

## 竞品

- 示例竞品A | XX 制药 | 直接 | 药品 | 100U/支 | 面部皱纹 | deep | price
- 示例竞品B | YY 生物 | 直接 | 三类器械 | 1ml/支 | 鼻唇沟填充 | shallow
- 示例竞品C | ZZ 医美 | 间接 | 三类器械 | 0.5ml/支 | 下颌轮廓 | shallow

> 这份清单只决定「深查谁」。**公告与附件里出现的其他同组企业不会被丢掉**：它们进产物的「新发现对手」区（N 行），带企业名、产品、规格、价格、来源。你觉得值得盯，就把它加进本清单，下期自动转成深/浅监控；不加也会每期保留，不会消失。

## 字段预设（深监控用，浅监控忽略）

```yaml
fields: price     # price=价格应对 22 项｜access=准入变动 22 项｜tender=招采动向 20 项｜all=全 36 项
```

- `price`：跟价、报降价、谈价时用；不取医保四件与预算量。
- `access`：医保目录调整、集采到期、新证落地时用；不取挂网价细节（F17–F21）与中选价 F24。
- `tender`：新批次公告、省级执行通知、医院招标时用；不取医保与挂网价细节。
- `all`：首次建档且用户要完整底座时用，行数会明显变多。
- 竞品行末的「预设」列可逐家覆盖本节；都没写则由技能按本期决策问题选。

## 产物文件名（可选，改这里就改文件名里的产品段）

```yaml
file_label: 保妥适(100U/支)   # 格式固定为「产品名称(规格)」；留空则按「竞品」段第一家的名称+规格自动生成
```

- 五份产物文件名都会带这一段，例如 `竞品监测-2026-11-11_0930-保妥适(100U／支).md`。
- 两家一起看时写成 `保妥适(100U/支)+乔雅登(1.0ml/支)`，最多两段，第三家起自动写「等N项」。
- 斜杠、冒号等 Windows 非法字符由技能自动替换，你不用改写成全角。

## 我方产品（E1 建议填，用于算价差；E2 必填）

- 通用名：示例我方产品
- 注册证号：国械注准 20253010000
- 适用范围：中重度鼻唇沟皱纹
- 医保编码：XJ01ABC000
- 目标省份：广东、江苏、浙江
- 主力规格：1.0ml/支

```yaml
our_price:
  - {spec: "1.0ml/支", basis: 挂网价, value: 1800, date: "2026-10-01", province: 广东}
  - {spec: "1.0ml/支", basis: 集采中选价, value: 980, date: "2026-10-15", project: 某省集采}
```

> `our_price` 是文档「5.1 价格对照」算价差的分母，**不填就整列写「未提供」，技能不会替你猜**。`basis` 取 `挂网价 / 挂网限价 / 集采中选价 / 供应价 / 中标价 / 零售价 / 医保支付标准` 之一（与竞品行同口径才能相减）；同一规格有多个口径就写多条，不同口径不比价。
> 目标省份只决定**挂网价**查哪几省（挂网价多需登录，成本高）；**集采项目的省份一律全展开**——国采 32 个省级单元、联盟文件列明的全部成员省，不受这里限制。竞品有多规格时，矩阵按规格分行，不合并成一个价。

## 领域扫描规则（E3 用；E1/E2 可留空）

```yaml
classification_codes: ["13-09-02"]     # 器械分类编码，多个用数组；药品可填剂型+治疗领域
keywords: ["透明质酸", "鼻唇沟"]        # 适用范围或产品名关键词
new_cert_months: 12                    # 「近 N 月新证」窗口
```

命中任一编码或关键词即视为同领域，纳入事件扫描范围。

## 启用信号位

## 阈值（不写则用默认）

```yaml
price_drop_red: 5%        # 竞品挂网价降幅达到此值判红，默认 5%
price_stale_days: 30      # 价格与挂网状态超过此天数标「需复核」
cert_stale_days: 90       # 注册证与目录资格超过此天数标「需复核」
cert_expiry_warn: 180     # 注册证到期前多少天预警，默认 180 天
calendar_days: 90         # 政策日历覆盖天数，默认 90 天
confirm_before_doc: true  # true=矩阵落盘后停下等你确认；false=自检通过即出文档
```

## 不监测（避免噪音，写进来的一律不查）

- 竞品融资、人事、合作等企业动作（如需监测，把 C8 加进扩展信号位）
- 电商与社交平台价格与口碑
- 未公开的销量、份额、投放数据
